# MD Card

Генератор красивых сайтов-визиток из Markdown. Редактор слева, live-превью справа, экспорт в автономный HTML.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # предпросмотр production-сборки
npm test         # тесты (Vitest); npx vitest --ui — в браузере
npm run check:dsl -- сайт.md   # проверить файл разметки (см. «Проверка разметки»)
```

## Формат Markdown

```markdown
---
name: Алексей Иванов
title: Frontend-разработчик
theme: auto          # auto | glass | minimal | noir | vercel
accent: auto         # hex-цвет (#ff5500) или auto — палитра из имени
avatar: https://...
location: Москва
links:
  - label: GitHub
    url: https://github.com/user
    icon: github
  - label: Email
    url: mailto:hello@example.com
    icon: mail
---

## О себе
Краткое описание.

## Навыки
React, TypeScript, Node.js

## Опыт
**Senior Developer** — Acme Inc, 2022–2026
Описание достижений.

## Контакты
Напишите на email или в Telegram.
```

## Дополнительные типы секций

Внутри любой секции `## Заголовок` можно использовать специальные блоки — тип определяется автоматически (`detectSectionType`).

### Таблица

Обычная Markdown-таблица: секция распознаётся по строкам с `|` и строке-разделителю из `-`.

```markdown
## Опыт

| Компания | Роль | Период |
|----------|------|--------|
| Acme Inc | Senior Developer | 2022–2026 |
| Startup Lab | Frontend Developer | 2020–2022 |
```

### Аккордеон / FAQ

Блок `:::accordion`, элементы разделяются пустой строкой:

```markdown
## FAQ

:::accordion
title: С какими технологиями вы работаете?
content: React, TypeScript, Node.js

title: Как связаться?
content: Напишите на email или в Telegram
:::
```

### Кодовый блок с подсветкой

Блок `:::code lang="..."`. Подсветка встроенная (без внешних библиотек): `typescript`, `javascript`, `json`, `css`, `html`, `python`, `bash`.

```markdown
## Пример кода

:::code lang="typescript"
const greet = (name: string): string => 'Привет, ' + name
console.log(greet('мир'))
:::
```

### Сетка карточек

Блок `:::cards`, элементы разделяются пустой строкой:

```markdown
## Проекты

:::cards
title: Дизайн-система
description: 36 переиспользуемых компонентов для 12 продуктов компании
icon: star
url: https://github.com/example/design-system
tags: React, Storybook, Tokens

title: Realtime-дашборд
description: Аналитика в реальном времени на WebSocket
icon: rocket
url: https://github.com/example/realtime-dashboard
tags: TypeScript, WebSocket, D3
:::
```

Поля карточки:

| Поле | Описание |
|------|----------|
| `title` | Название проекта |
| `description` | Краткое описание (можно переносить на несколько строк — строки без ключа допишутся к описанию) |
| `icon` | Иконка (см. список ниже) |
| `url` (или `link`) | Ссылка на проект: вся карточка становится кликабельной, под описанием показывается адрес |
| `tags` | Стек/теги через запятую — выводятся чипами |

Доступные иконки: `star`, `rocket`, `code`, `briefcase`, `heart`, `globe`, `user`, `zap`, `github`, `mail`, `telegram`, `link`, `phone`, `whatsapp`, `vk`, `instagram`, `max`, `map-pin`.  
Незакрытый блок (без строки `:::`) поглощает всё, что ниже, — валидатор предупредит и предложит закрыть. Строки `##` внутри блока не считаются заголовками.

### Услуги

Блок `:::services` — услуги с ценой и кнопкой «Записаться». Кнопка ведёт на главный контакт из шапки (`contacts.primary`, иначе телефон):

```markdown
## Услуги и цены
:::services
title: Мужская стрижка
price: 1500
duration: 60 мин
description: Машинкой и ножницами, мытьё головы и укладка

title: Оформление бороды
price: от 800
:::
```

| Поле | Описание |
|------|----------|
| `title` | Название услуги (обязательно) |
| `price` | Цена числом: `1500`, `от 1500`, `1500–2000` или словом `бесплатно`. Знак ₽ сайт добавит сам (валюта — `currency` в шапке) |
| `duration` | Сколько длится: `60 мин` |
| `description` | Что входит в услугу |

Валидатор подскажет, если цена записана с валютой («1500р» → `1500`), услуга повторяется или у неё нет описания.

### Часы работы

Блок `:::hours` — по строке на дни, по-русски. Над таблицей — отметка «Открыто до 20:00» или «Закрыто, откроемся завтра в 10:00»; на опубликованном сайте она пересчитывается при каждом открытии страницы по часам посетителя:

```markdown
## Часы работы
:::hours
пн–пт: 10:00–20:00
сб: 11:00–18:00
вс: выходной
:::
```

Дни: `пн`…`вс`, полные названия, диапазоны `пн–пт`, списки `пн, ср, пт`, слова `ежедневно`, `будни`, `выходные`. Время: `10:00–20:00`, `10-20`, `с 9 до 21`, `выходной`, `круглосуточно`. Валидатор подскажет, если строка непонятна, закрытие раньше открытия («10:00–8:00» → «до 20:00?»), день указан дважды или какие-то дни пропущены.

### Отзывы

Блок `:::reviews` — карточки отзывов со звёздами; при двух и более отзывах сверху показывается средняя оценка:

```markdown
## Отзывы
:::reviews
author: Алексей
text: Лучший фейд в городе, мастер не торопится
rating: 5
date: март 2026

author: Ольга
text: Привожу сына уже год, всегда аккуратно
rating: 5
:::
```

`author` и `text` обязательны, `rating` — число от 1 до 5 (валидатор исправит «5/5», «★★★★★», «5 звёзд»), `date` — как удобно: «март 2026».

### Карта

Блок `:::map` — карта Яндекса с меткой и кнопки «Яндекс Карты» и «2ГИС». Адрес берётся из шапки (`city` + `address`), координаты и ключи не нужны; карта загружается, только когда посетитель до неё долистает:

```markdown
## Как добраться
:::map
:::
```

Если карта должна показывать другое место — `address: Московское ш., 1` внутри блока.

### Контакты

Блок `:::contacts` показывает телефон, адрес и кнопки мессенджеров. Внутри ничего писать не нужно — данные берутся из шапки (`phone`, `address`, `city`, `contacts`), ссылки сайт строит сам:

```markdown
---
name: Барбершоп «Борода»
phone: +7 999 123-45-67
address: ул. Ленина, 10
city: Самара
contacts:
  telegram: barber_ivan       # → https://t.me/barber_ivan
  whatsapp: +7 999 123-45-67  # → https://wa.me/79991234567
  max: https://max.ru/u/…     # ссылка на профиль: в MAX откройте профиль → QR-код → «Поделиться»
  vk: barber_samara           # → https://vk.com/barber_samara
  email: hello@barber.ru      # → mailto:
---

## Контакты
:::contacts
:::
```

Телефон становится ссылкой `tel:` — на смартфоне по нажатию сразу открывается звонок.

### Панель связи на телефоне

Отдельно писать ничего не нужно: если в шапке есть телефон или мессенджеры, на узком экране внизу закрепляются до трёх кнопок — «Позвонить», Telegram, WhatsApp (MAX, ВКонтакте). Главный контакт (`contacts.primary`) — первым и залитым цветом. На широком экране панели нет; в редакторе её видно, если сузить превью.

### Разделитель без названия

`##` без названия (можно с пробелами после) — граница «куска» внутри текущей секции: содержимое остаётся в этой секции, а на месте `##` появляется тонкая линия-разделитель.

```markdown
## Опыт
**Senior Developer** — Acme Inc, 2022–2026
Описание достижений.

##

**Frontend Developer** — Startup Lab, 2020–2022
Описание.
```

Если `##` стоит до первой именованной секции — содержимое становится безымянным блоком без заголовка (текст до первого `##` тоже больше не теряется).

## Шаблоны

При создании сайта можно выбрать готовый шаблон: **барбершоп**, **маникюр**, **репетитор**, **фотограф** или пустой сайт (`src/data/templates/`). Название сайта подставляется в шаблон, остальное — пример, который нужно заменить своим: телефон `+7 900 000-00-00`, имя в Telegram, адрес, цены. Отзывы в шаблонах — заготовки: вставьте настоящие отзывы клиентов. Барбершоп открывается в редакторе по умолчанию и по кнопке «Пример».

## Сайт по описанию

Кнопка **«Создать сайт по описанию»** в списке сайтов: опишите бизнес своими словами (что делаете, цены, адрес, часы, как связаться) и выберите вид бизнеса. Edge Function `generate-site` просит GigaChat составить разметку, сама проверяет её валидатором и исправляет — сначала автоматически, оставшиеся ошибки отправляет нейросети (до 3 попыток). Перед показом контакты и ссылки сверяются с описанием: выдуманный телефон или аватар удаляется. Готовый сайт открывается в редакторе; то, чего не хватает (нет телефона, описаний услуг), редактор подскажет добавить.

Каждое обращение к нейросети пишется в таблицу `generation_logs` (для эксперимента ВКР). Лимит — 20 генераций в сутки (`GENERATION_DAILY_LIMIT`). Проверка на наборе описаний:

```bash
# access_token приложения скопирован в буфер (DevTools → Application → Local Storage)
./experiments/run-step8.sh               # описания из experiments/prompts.json × режимы markdown и json
MODES=json MODEL=GigaChat-2-Max ./experiments/run-step8.sh
```

Ответы сохраняются в `experiments/results/<дата-время>/` (в git не попадают). Тесты функций — `npm run test:functions` (Deno).

## Редактор

Редактор построен на CodeMirror 6 (`src/editor/`) и знает язык разметки по той же схеме, что и валидатор:

- **подсветка**: шапка, `:::блоки`, ключи полей, заголовки `##`, числа и строки в кавычках;
- **ошибки подчёркиваются** прямо в тексте (красным — ошибки, жёлтым — предупреждения); при наведении — объяснение и кнопка исправления, если ответ однозначен;
- **панель «Проблемы»** под редактором: счётчик и список, клик переводит к месту, кнопка «Исправить»;
- **подсказки при наборе**: после `:::` — блоки с готовой заготовкой (Tab — к следующему значению), в начале строки — поля шапки или блока, после `theme:` / `business:` / `icon:` и внутри `contacts:` — допустимые значения. Ctrl+Space — открыть подсказки вручную;
- **справка при наведении** на `:::блок` или ключ поля — описание из схемы;
- **«+ Блок»** над редактором — форма по схеме блока: заполните поля, проверьте замечания и вставьте готовую разметку;
- **клик по блоку в превью** переводит курсор к его строке.

Для эксперимента редактор умеет записывать события (подсказка показана/принята, ошибка появилась/исправлена) в таблицу `editor_events`. По умолчанию выключено; включить на одном компьютере — в консоли браузера `localStorage.setItem('md-card:editor-events', 'on')`, для всей сборки — `VITE_EDITOR_EVENTS=on` в `.env`.

## Проверка разметки

Валидатор находит ошибки в разметке и объясняет их по-русски, с номером строки и, где ответ однозначен, с автоисправлением:

```bash
npm run check:dsl -- сайт.md
pbpaste | npm run -s check:dsl     # текст из буфера обмена (macOS)
```

```
stdin:3:8  внимание  [invalid-value]
  Значение «noire» не подходит для поля «theme». Возможно, вы имели в виду «noir»?
  Исправление: Заменить на noir
stdin:7:1  ошибка  [unclosed-fence]
  Блок :::accordion не закрыт — всё, что ниже, попадёт в него. Добавьте строку ::: в конце блока
  Исправление: Закрыть блок
```

Что проверяется:
- **синтаксис**: шапка (ошибки YAML — понятным языком: двоеточие в значении, Tab, `@` в начале), незакрытый и вложенный `:::`, `##Цены` без пробела, заголовки с переводами строк Windows;
- **схема языка**: обязательные поля, неизвестные блоки и поля, недопустимые значения (тема, вид бизнеса, иконка, ссылка без `https://`, цвет без кавычек);
- **опечатки** — «возможно, вы имели в виду»: `telegramm` → `telegram`, `:::card` → `:::cards`, `телефон:` → `phone:`, `tg` → `telegram`;
- **контакты**: нет ни телефона, ни мессенджера; телефон не в виде `+7 999 123-45-67`; ссылка или `@имя` вместо имени пользователя; имя Telegram не по правилам; WhatsApp не номером; `primary` на неуказанный контакт; адрес без города.

Поля бизнеса в шапке (показываются блоком `:::contacts` и другими блоками бизнеса):

```yaml
business: barbershop        # barbershop | tutor | nails | photographer | other
phone: +7 999 123-45-67
address: ул. Ленина, 10
city: Самара
currency: RUB
contacts:
  telegram: barber_ivan     # имя пользователя, без @ и ссылки
  max: https://max.ru/u/…   # в MAX — ссылка на профиль
  whatsapp: +7 999 123-45-67
  primary: telegram         # куда ведёт главная кнопка: контакт или phone
```

Язык описан в `src/dsl/` (чистый TypeScript, работает и в браузере, и в Supabase Edge Functions):
`schema/` — схема на Zod (поля, блоки, иконки, описания), `parser.ts` — разбор в дерево с позициями, `validate.ts` и `rules/` — правила, `serialize.ts` — данные обратно в разметку, `prompt.ts` — системный промпт для нейросети из той же схемы.

## Темы

| Тема | Стиль |
|------|-------|
| **Glass** | Frosted glass, blur-эффекты |
| **Minimal** | Типографика Playfair + Inter, много воздуха |
| **Noir** | Тёмный фон, neon accent, monospace |
| **Vercel** | Чёрный фон, тонкие бордеры, Geist / Geist Mono, моно-лейблы |

При `theme: auto` тема выбирается по ключевым словам в title и секциях.  
При `accent: auto` цвет генерируется из hash имени — стабильный и уникальный (можно задать свой hex-цвет, например `accent: "#ff5500"`).  
Тема **Vercel** монохромная: `accent` для неё игнорируется — используются только чёрный, белый и оттенки серого.

## Экспорт

Кнопка **Экспорт HTML** скачивает один `.html` файл со встроенными стилями и шрифтами. Файл работает без сервера; единственный встроенный скрипт — пересчёт «Открыто до …», если есть блок часов работы.

Для поисковиков и мессенджеров в `<head>` добавляются:
- `<meta name="description">` и Open Graph (`og:title`, `og:description`, `og:image` — из `avatar`) — превью ссылки в Telegram и ВКонтакте;
- для сайта бизнеса — разметка [Schema.org](https://schema.org) `LocalBusiness` (JSON-LD): адрес, телефон, часы работы, услуги с ценами, отзывы и средняя оценка, ссылки на соцсети. Тип — `HairSalon` для барбершопа, `NailSalon` для маникюра, иначе `LocalBusiness`. Проверить: скопировать HTML в [validator.schema.org](https://validator.schema.org).

Кнопка **Экспорт PDF** сохраняет текущее превью как PDF-документ.

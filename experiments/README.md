# experiments/ — материалы экспериментов ВКР

Протоколы и выводы — `PLAN.md` (этап 5 — доработка обработки, этап 7 — эксперимент 1). Здесь — данные, скрипты и разборы.

## Что где лежит

### Описания бизнесов (вход генерации)

| Файл | Что это |
|---|---|
| `prompts.json` | 13 описаний — **набор для доработки** (этап 5): на нём находили и чинили ошибки обработки. В эксперимент 1 не входит |
| `prompts-exp1.json` | 48 описаний — **отложенная выборка** эксперимента 1: на ней ничего не настраивали (ни промпт, ни обработку). Теги сложности и `niche:<ниша>` — в поле `tags` |

### Скрипты эксперимента 1 (Node.js 24, TypeScript без сборки)

| Файл | Что делает |
|---|---|
| `run-generation.ts` | Прогон: описания × модели × режимы × повторы через задеплоенную функцию `generate-site`. Можно прерывать и продолжать |
| `export-logs.ts` | Выгрузка `generation_logs` по запускам прогона → CSV-метрики и пакет для ручной разметки |
| `common.ts` | Общее: настройки, вход тестового аккаунта, условия эксперимента (модели, режимы, повторы, замороженная версия обработки) |
| `stub-supabase.ts` | Локальная заглушка Supabase — проверка скриптов без GigaChat и без расхода лимита |

Подробные параметры — в заголовке каждого файла.

## Как запустить

Настройки — `experiments/.env.local` (в git не попадает): `EXP_EMAIL`, `EXP_PASSWORD` тестового аккаунта.

```bash
node experiments/run-generation.ts --dry-run     # план прогона без сети
node experiments/run-generation.ts               # весь прогон; Ctrl+C — остановка, та же команда — продолжение
node experiments/export-logs.ts                  # results/exp1/runs.jsonl → CSV и annotation/

# графики (нужен matplotlib)
python3 -m venv ~/.venvs/mdcard && ~/.venvs/mdcard/bin/pip install matplotlib
~/.venvs/mdcard/bin/python experiments/figures/exp1_report.py
```

Проверка скриптов на заглушке — команды в заголовке `stub-supabase.ts`.
